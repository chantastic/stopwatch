Install from your browser

Use Chrome or Edge on a computer and a USB-C cable that carries data. Close other apps connected to the badge.

  1. Connect your M5Stack StopWatch.
  2. Choose its USB port when prompted.
  3. Keep it connected until the clock and storage checks finish.

This preview updates badges already prepared with our conference storage layout. Your saved profile and settings stay on the badge.

USB installation needs desktop Chrome or Edge. Open this page directly in that browser. You can still read the guide and download the build here.

Ready when you are. Installation stays between this browser and your badge.

STARTING FROM STOCK?
First install

        
M5Stack’s factory firmware uses a different storage layout. This installer stops before writing to those devices. Factory conversion is still being qualified.

        
Keep the original firmware for now, or let us know you’d like to test a factory install.

        
If the browser cannot connect, check the cable, close serial monitors, and reconnect USB. A clock-check failure does not mean a verified firmware write was undone.
