Install from your browser

Use Chrome or Edge on a computer and a USB-C cable that carries data. Close other apps connected to the badge.

  1. Connect your M5Stack StopWatch.
  2. Choose its USB port when prompted.
  3. Keep it connected until the clock and storage checks finish.

Starting with a new StopWatch? First install saves a recovery copy, then replaces the factory software and storage. Updating a conference badge keeps your saved profile and settings.

USB HELP
A fresh start, right here.

        
You don’t need Arduino. If the browser cannot connect, keep USB plugged in, hold the power button for about two seconds until the green light comes on, then release it and try again.

        
Use a data cable and close serial monitors. Only the verified M5Stack factory storage layout is supported. Your recovery copy stays on your computer; don’t attach it to issue reports.

        
Finish an interrupted first install
          
Keep your recovery copy. Try Set clock & check badge first. If the firmware write was interrupted, use Update badge to finish it.

          
If the conference firmware is installed but storage still needs preparation, this step checks the badge and prepares storage only when it cannot be opened. Working storage is kept.
