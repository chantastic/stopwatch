NOTE

Conference badge: use the browser installer for the init() build, or follow the Arduino guide below to develop your own firmware. Installing firmware replaces the device’s application; keep any image you want to restore.

Arduino setup checklist+
  1. Install the M5Stack package through Arduino Board Manager. Use version 3.3.7 or newer and select M5StopWatch.
  2. Install M5Unified 0.2.15+ and M5GFX 0.2.21+ with their dependencies.
  3. Connect a USB-C data cable. Hold the power/reset button for about 2 seconds until the green LED turns on, then release.
  4. Select the device’s port. Compile and upload the official display example.

Restore M5Stack’s factory firmware with M5Burner. This restores the manufacturer’s demo, not an init() custom image.

Expansion pins — hardware revision notice+

On some v1.0 units, the rear pin printed “BAT” is actually 5V IN. Do not connect a battery to that pin. On v1.0.1, the “*BAT” marking refers to the battery pin. Read M5Stack’s sticker correction and revision-specific pin map before wiring accessories.
